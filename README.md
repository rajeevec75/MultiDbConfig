# MultiDb Config Spring Boot Project

This Spring Boot project demonstrates how to configure and integrate **multiple databases** (MySQL and PostgreSQL) within a single application using Spring Data JPA.

## 📌 Features

- ✅ Multiple DataSource configuration
- ✅ Separate JPA repositories for MySQL and PostgreSQL
- ✅ RESTful API endpoints to manage data from both databases
- ✅ Organized structure for scalability and maintainability

## 🧱 Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- PostgreSQL
- Maven
